# GitHub & Django Exercise

## Objective
Apply the wireframes assigned to you provided on the whiteboard using the Django framework.

## Instructions

### 1. Clone the Repository
Clone the project repository to your local machine:

```bash
git clone <repository-url>
```

### 2. Create a New Branch
Create and switch to a branch dedicated to your assigned task:

```bash
git checkout -b feature/<your-feature-name>
```

### 3. Implement Your Assigned Part ONLY
- Work only on the section assigned to you.
- Follow the provided wireframes carefully.
- Use the class names and attributes specified in the exercise requirements.

### 4. Commit Your Changes
Commit your work with clear and meaningful commit messages:

```bash
git add .
git commit -m "Implement assigned feature"
```

### 5. Push Your Branch
Push your branch to GitHub:

```bash
git push origin feature/<your-feature-name>
```

### 6. Create a Pull Request
- Open a Pull Request (PR) from your branch to the `master` branch.
- Request a review from your instructor or teammates.

### 7. Resolve Merge Conflicts
If conflicts occur:
- Pull the latest changes.
- Resolve conflicts locally.
- Push the updated branch.

### 8. Merge Your Code
Once your Pull Request is approved, merge it into the `master` branch following the GitHub Pull Request workflow.

---

## Deliverables

- A separate feature branch.
- Clean and well-structured Django code.
- Meaningful commit history.
- An approved Pull Request merged into `master`.
